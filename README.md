# Training Collector Admin

Отдельное приложение на React и TypeScript для одобрения регистраций, управления тренерами, общими упражнениями и целями.

## Локальный запуск

Нужны Node.js 22.12+ и бэкенд Training Collector с административным API. В окружении **бэкенда** установите `ADMIN_LOGIN` и `ADMIN_PASSWORD` и перезапустите его. На странице входа введите эти значения. Пароль не включается в сборку сайта.

```sh
cp .env.example .env
npm ci
npm run dev
```

Админка по умолчанию открывается на `http://localhost:5174`. Если порт занят, Vite пробует следующие по порядку и выводит выбранный адрес в терминале. `BACKEND_URL` по умолчанию равен `http://127.0.0.1:8080`. Для production-сборки выполните `npm run build`. Запросы к `/admin/v1/*` проксируются на `BACKEND_URL`. Развёртывание вместе с остальными сервисами описано в `training-collector-deploy`: админка открывается на отдельном домене.

## Работа

- В **Заявках** нажмите **Одобрить** после того, как тренер запустил бота авторизации по ссылке с сайта. В заявке показан Telegram ID заявителя. Открытая страница регистрации перейдёт к подтверждению входа в Telegram. Если тренер вернётся позже, он сможет войти по Username.
- В **Тренерах** можно деактивировать аккаунт с сохранением данных или удалить его вместе с подопечными, тренировками и замерами.
- В разделе **Упражнения** создайте категорию, откройте её и добавьте упражнения. Кнопка **Изменить** рядом с категорией позволяет поменять название и описание, кнопка **Удалить** убирает категорию без упражнений. В форме редактирования упражнения можно перенести его в другую категорию.
- В **Упражнениях** и **Целях** можно создать, изменить, скрыть, вернуть в список или удалить запись. Скрытие и удаление убирают её из вариантов для новых записей. Исторические тренировки и карточки подопечных сохраняются.
